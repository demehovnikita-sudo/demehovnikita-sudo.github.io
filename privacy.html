Политика конфиденциальности

Дата последнего обновления: 15 октября 2026 г.

Настоящая Политика конфиденциальности описывает порядок обработки информации при использовании мобильных приложений, разработанных Самозанятым Демеховым Никитой Вячеславовичем (далее — «Разработчик»).

1. Общие положения

Разработчик уважает конфиденциальность пользователей и стремится минимизировать сбор данных.

Если иное прямо не указано в конкретном приложении, Разработчик самостоятельно не собирает и не хранит такие персональные данные, как имя, адрес, номер телефона, данные банковских карт или иные сведения, позволяющие непосредственно идентифицировать пользователя.

2. Локальные данные приложения

Некоторые приложения могут сохранять на устройстве пользователя данные, необходимые для работы приложения, например:

  • настройки;
  • прогресс;
  • историю действий;
  • избранные элементы;
  • результаты тестов;
  • иные локальные данные приложения.

Такая информация хранится на устройстве пользователя и, если функционалом приложения не предусмотрено иное, не передаётся Разработчику.

3. Рекламные сервисы

В приложениях может использоваться Yandex Mobile Ads SDK / Рекламная сеть Яндекса для показа рекламы.

Рекламный SDK может автоматически обрабатывать техническую информацию, необходимую для показа, настройки и оценки эффективности рекламы. В частности, при наличии соответствующих разрешений может использоваться рекламный идентификатор устройства и иные идентификаторы устройства. Яндекс Реклама

Такая обработка выполняется непосредственно сторонним сервисом в соответствии с его собственными правилами и политиками.

Разработчик не получает доступ к содержимому личных сообщений пользователя, контактам, фотографиям, документам или другим личным данным пользователя через Yandex Mobile Ads SDK в его стандартной конфигурации. Яндекс Реклама

4. Цели использования информации

Информация может использоваться для:

  • обеспечения работы приложения;
  • сохранения пользовательских настроек и прогресса;
  • показа рекламы;
  • оценки эффективности рекламы;
  • обеспечения стабильности и безопасности работы приложения;
  • выполнения требований законодательства.

5. Передача данных сторонним сервисам

Разработчик самостоятельно не продаёт персональные данные пользователей.

Отдельные данные могут передаваться сторонним сервисам, встроенным в приложение, в частности рекламным SDK, если это необходимо для их работы.

Обработка такой информации осуществляется соответствующими сервисами в рамках их собственных правил конфиденциальности.

6. Разрешения устройства

Если конкретному приложению требуется доступ к функциям устройства, например камере, файлам, уведомлениям или другим возможностям, такой доступ запрашивается только для реализации соответствующей функции приложения.

Отказ от предоставления разрешения может ограничить работу только той функции, для которой оно требуется.

7. Безопасность

Разработчик принимает разумные меры для защиты информации, используемой приложениями.

Yandex Mobile Ads SDK, согласно документации Яндекса, передаёт поддерживаемые им пользовательские данные через защищённое HTTPS/TLS-соединение. Яндекс Реклама

8. Изменения Политики

Политика может периодически обновляться.

Актуальная версия публикуется на странице Разработчика или по ссылке, указанной в карточке приложения.

02 / PRIVACY

Privacy policy

Last updated: October 15, 2026

This Privacy Policy describes how information is processed when using mobile applications developed by the self-employed developer Nikita Vyacheslavovich Demekhov (the “Developer”).

1. General provisions

The Developer respects users’ privacy and seeks to minimize data collection.

Unless expressly stated otherwise in a particular application, the Developer does not independently collect or store personal data such as names, addresses, telephone numbers, bank card details, or other information that directly identifies a user.

2. Local application data

Some applications may save data on the user’s device that is necessary for the application to work, for example:

  • settings;
  • progress;
  • activity history;
  • favorites;
  • test results;
  • other local application data.

This information is stored on the user’s device and is not transmitted to the Developer unless the application’s functionality provides otherwise.

3. Advertising services

Applications may use the Yandex Mobile Ads SDK / Yandex Advertising Network to display advertisements.

The advertising SDK may automatically process technical information needed to display and configure advertisements and measure their effectiveness. In particular, with the relevant permissions, it may use the device’s advertising identifier and other device identifiers. Yandex Advertising

This processing is performed directly by the third-party service in accordance with its own rules and policies.

In its standard configuration, the Yandex Mobile Ads SDK does not give the Developer access to the contents of users’ private messages, contacts, photos, documents, or other personal data. Yandex Advertising

4. Purposes of information use

Information may be used to:

  • operate the application;
  • save user settings and progress;
  • display advertisements;
  • measure advertising effectiveness;
  • maintain the stability and security of the application;
  • comply with legal requirements.

5. Transfer to third-party services

The Developer does not independently sell users’ personal data.

Certain data may be transmitted to third-party services integrated into an application, in particular advertising SDKs, where this is necessary for them to operate.

This information is processed by the relevant services under their own privacy rules.

6. Device permissions

If a particular application needs access to device functions, such as the camera, files, notifications, or other capabilities, this access is requested only to implement the corresponding application feature.

Declining a permission may limit only the feature that requires it.

7. Security

The Developer takes reasonable measures to protect information used by the applications.

According to Yandex documentation, the Yandex Mobile Ads SDK transmits the user data it supports over a secure HTTPS/TLS connection. Yandex Advertising

8. Policy changes

This Policy may be updated from time to time.

The current version is published on the Developer’s page or at the link provided in the application listing.
